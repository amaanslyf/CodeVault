# CodeVault CLI

A beginner-friendly version control system CLI tool.

## Installation

npm install -g codevault-cli

text

## Usage

### Login
codevault login

text

### Initialize Repository
codevault init

text

### Add Files
codevault add <file>
codevault add . # Add all files

text

### Commit
codevault commit -m "Your commit message"

text

### Push
codevault push

text

### Pull
codevault pull

text

### Revert
codevault revert <commitId>

text

## Configuration

Set custom API URL:
export CODEVAULT_API_URL=https://your-api.com
